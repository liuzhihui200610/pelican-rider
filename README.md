# 鹈鹕骑手 3D（Pelican Rider）

一个**真正用游戏引擎做的 3D 跑酷游戏**：Godot 4.7 引擎 + Vulkan Forward+ 渲染 + 真实刚体物理。
不是网页小游戏 —— 有引擎、有渲染管线、有物理引擎、有音效、有粒子、有完整 UI。

> **当前版本 V109**。主角鹈鹕由**运行时骨架蒙皮**驱动 —— 会**蹬腿、扇翅、回头看**。
> 项目规模：`main.gd` 3353 行（66 函数）+ `pelican_rig.gd` 403 行 · 11 个自写 shader · 25 个工具脚本。
> 真机实测：高档 **~80 FPS**（1.5× 超采样 + 8× MSAA 全开）/ 中低档 **~135 FPS**。详见 `项目现状报告-20261005.md`。

## 怎么玩（最简单）

双击项目根目录的 **`Play-PelicanRider.bat`** —— 直接进入游戏窗口。

> **首次启动请耐心等 15~30 秒**：Godot 第一次运行要编译着色器（自写 shader + SDFGI + SSR），
> 这期间窗口可能还没出现，不是卡死。之后启动会快很多。

### 双击打不开？按顺序排查

1. **`Diagnostics.bat`** —— 双击它。它只开一个黑色命令行窗口（**不会弹游戏窗口**），
   会告诉你 Godot 在哪、工程文件在不在、并跑一次无界面自检。`[BOOT] ok` / `[VERIFY]` 出现即表示工程没问题。
2. **`Play-Debug.bat`** —— 前台运行 Godot，**所有报错直接留在屏幕上**，退出后暂停等你按键。
   把红字/报错内容发给我，我照着修。
3. 常见原因：首次着色器编译慢（等一会儿）、Windows SmartScreen 拦截（右键 exe → 属性 → 解除锁定）。

- **空格 / ↑ / W** = 跳跃（真实物理冲量）
- **A / D 或 ← / →** = 左右转向（车身会侧倾）
- 躲开路障 / 油桶 / 石头，吃小鱼涨分，**连击**有额外加分，**擦身而过**也有奖励分
- 撞上障碍 = 翻车（慢动作 + 羽毛四溅 + 相机震动），**R / 空格 / 按钮** 重来
- 最高分会**自动存档**，下次打开还在

## 这个游戏里有什么

| 类别 | 内容 |
|---|---|
| **AI 3D 模型** | 混元 3D 管线生成（`assets/ai/`，每个带 GLB + preview + PBR 三图）：**主角鹈鹕**（**V109 起是可动骨架角色**）、棕榈、路灯、小屋、灌木、帆船 |
| **程序化模型** | `tools/build_assets.py` 生成（纯 Python 标准库）：自行车全零件（轮/辋/辐条/车架/车把/座垫/曲柄脚踏）、路障（锥/桶/石/轮胎堆/水马）、护栏、遮阳伞、草丛、石头、树、招牌、海鸥 |
| **渲染** | 自写**赛璐璐卡通 shader** + **反向壳描边** + **程序化天空** + **晕影后期**（共 11 个 shader）；ACES 色调映射、辉光、SSAO/SSIL/SSR、体积光、4 级 CSM 阴影、程序化路面/海面/草地多层材质（车辙/积水/裂缝/标线磨损/岸线泡沫/风扫草浪） |
| **物理** | Godot 刚体物理：车体是真实刚体（质量 / 重力 / 惯性 / 低摩擦物理材质），前进靠持续施力、跳跃靠冲量；障碍物是可被撞飞的刚体；翻车解除旋转锁定 → 真实翻滚 |
| **角色动画** | **运行时骨架蒙皮（V109）**：8 根骨（骨盆/躯干/头/左右翅/尾/左右腿）；腿**与车轮曲柄同相位**蹬踏、空中扇翅、擦身回头 42°、吃鱼啄食、撞车前甩 + 围巾飘动 |
| **粒子** | 车轮扬尘（持续）、吃鱼金色火花（一次性）、撞车白色羽毛爆炸 |
| **音效** | 程序合成 WAV：跳跃上滑音、收集双音、撞车噪声+低频闷响、8 秒无缝循环 BGM 琶音 |
| **UI** | 卡片式 HUD（圆角半透明 + 描边 + 阴影）、速度条、连击提示、开始界面、结束结算界面；**F3 调试 HUD**（FPS/帧时间/物理/节点数/DrawCall/状态机…） |
| **玩法** | 无限跑酷：距离计分 + 吃鱼 + 连击加成 + 擦身奖励 + 速度渐增（相机 FOV 随速度拉伸） |
| **节奏** | 起步 11 m/s、最高 26 m/s、加速度 8；**前方 200 米始终预生成** |

## 项目结构

```
PelicanRider-Godot/
├── Play-PelicanRider.bat   ← 双击启动游戏
├── project.godot           ← 引擎工程配置（Vulkan / MSAA / 物理）
├── scenes/Main.tscn        ← 主场景
├── scripts/main.gd         ← 主逻辑（3353 行 / 66 函数）
├── scripts/pelican_rig.gd  ← ★ V109 运行时骨架蒙皮器（403 行）
├── shaders/                ← 11 个自写 shader
├── assets/ai/              ← AI 生成的 GLB（混元 3D 管线）
├── assets/                 ← 程序化贴图 / 低模 OBJ / 合成 WAV
├── tools/                  ← 生成器 + 验证脚本（rig_selftest.gd / parsecheck.sh / v109_verify.sh …）
├── logs/                   ← 分版本的测试与性能日志
├── _archive/               ← 历史诊断产物（含 .gdignore，Godot 会忽略）
├── 项目现状报告-20261005.md  ← 逐项磁盘实测的现状报告（以它为准）
├── CHANGELOG.md            ← 100+ 版本血泪记录
└── AI交接文档.md            ← 给下一个 AI 的交接说明
```

> ⚠️ **`EXIT=0` 是假绿** —— Godot 即使有脚本错误也可能返回 0。必须 grep 五项错误计数。
> ⚠️ **验证时绝不弹游戏窗口抢焦点**（用户在用电脑）。

## 想改东西？

- 改手感：`scripts/main.gd` 顶部的常量（速度 / 加速度 / 跳跃力 / 转向灵敏度）
- 改角色动作：`scripts/pelican_rig.gd` 的 `pose_bones()`；**改完必跑 `tools/rig_selftest.gd`**
- 改配色：shader 里的 uniform 或 main.gd 里 `_toon(Color(...))` 的颜色
- 改程序化模型：`tools/build_assets.py` 改参数后重新运行即可重新生成
